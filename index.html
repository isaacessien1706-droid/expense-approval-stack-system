Why This Application Strictly Requires a Stack

  • Hierarchical Escalation (push): Each managerial sign-off builds directly on top of the previous level's verification.
  • Single-Step Audit Rollback (pop): When an Executive Director queries an invoice, they don't revoke the Employee's original submission—they pop() the top stamp so it returns directly to the Finance Manager immediately beneath them.
